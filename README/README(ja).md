## GeyserVoice - Minecraft 近接音声チャット プラグイン

GeyserVoice は、[VoiceCraft](https://github.com/SineVector241/VoiceCraft-MCBE_Proximity_Chat/) 近接チャット アプリケーションを統合することで、Minecraft サーバーでのマルチプレイヤー ゲーム体験を強化するように設計された Java プラグインです。このプラグインはクロスプラットフォーム通信を容易にし、Java エディションと Bedrock エディションの両方のプレイヤーが近接ベースの音声会話にシームレスに参加できるようにします。

### 機能

- クロスプラットフォーム通信:
GeyserVoice は Minecraft Java エディションと Bedrock エディションの間のギャップを埋め、異なるプラットフォームのプレイヤーが VoiceCraft 近接チャット システムを通じて通信できるようにします。

- 没入型近接チャット:
近接ベースの音声チャットで、より没入型でリアルなゲームプレイ環境を体験してください。近くのプレイヤーと会話に参加し、チームワークと連携を強化します。

### 仕組み

インストール: Minecraft Java サーバーに GeyserVoice プラグインをインストールするだけです。セットアップ手順に従って、VoiceCraft Proximity Chat アプリケーションとシームレスに統合してください。

### はじめに

GeyserVoice のインストールと構成の詳細な手順については、このリポジトリの [Wiki](https://github.com/AvionBlock/GeyserVoice/wiki/) セクションを参照してください。

### ライセンス

GeyserVoice は MIT ライセンスの下でライセンスされています。ライセンスの条件に従って、プラグインを自由に使用、変更、配布できます。

### プロキシ サーバーのサポート

GeyserVoice は、Velocity および Bungeecord ネットワークでの使用もサポートしています。プロキシ サーバーとペーパー サーバーに .jar をインストールするだけです。ペーパー サーバーの設定を編集して、`server-behind-proxy` を `true` に設定し、`voice reload` を使用してリロードしてください。追伸: ペーパー サーバーでサーバー アドレス、ポート、キーを設定する必要はありません。これはプロキシ サーバーでのみ必要です。
